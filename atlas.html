01 — THE QUESTION

Not “can we read minds?”
Can we find useful signal?

Participants meditate wearing EEG caps, then rate their own concentration, mind wandering, or meditation depth. We investigate whether preceding EEG helps predict those subjective reports.

Feature question

Can two understandable measurements compete with much richer descriptions of the EEG?

Algorithm question

With the same input measurements, does a more flexible model perform better?

Validation question

Do predictions generalize to people not used during training?

03 — FEATURE ENGINEERING

One brain recording. Different ways to describe it.

A feature is a numerical description of a signal. We don't train on “focus” itself: we train on measurements of EEG, paired with the participant's reported rating.

01 / POWER

Gamma ÷ theta

How strong is the fast gamma band (30–45 Hz) relative to slower theta (4–8 Hz)? The quotient is a candidate feature, not a concentration meter.

04 — MODEL LAB

Which helps more: features or complexity?

Ridge learns regularized weighted combinations. Gradient boosting builds many decision trees. Riemannian ridge transforms covariance matrices, then still uses ridge regression.

LINEAR + REGULARIZATION

Ridge regression

Fits feature weights while penalizing extreme weights. Useful when many EEG features are correlated.

prediction = Σ(weight × feature) + bias
NONLINEAR PATTERNS

Gradient boosting

Combines many small decision trees, each improving the ensemble. Can capture thresholds and interactions ridge may miss.

prediction = initial + tree₁ + tree₂ + …
DIFFERENT REPRESENTATION

Riemannian ridge

Converts covariance matrices to tangent-space vectors, then fits a regularized linear predictor.

covariance → tangent features → RidgeCV

05 — SCIENTIFIC VALIDATION

How do we stop a model from fooling us?

A good training score isn't proof of a useful EEG effect. The project uses independent participants, non-EEG comparisons, permutation tests, and multiple-testing correction.

01 / LEAVE-ONE-SUBJECT-OUT

Train on everyone else. Test on one unseen person.

Each participant's entire set of recordings stays out of model training in their test round. With 39 people, the depth experiment runs 39 held-out-person rounds per model.

04 / MULTIPLE TESTING

Holm correction

Testing many models raises the chance of a misleadingly small p-value. Holm adjusts p-values across a defined family of tests.

The work doesn't end with a model comparison.

Each follow-up tests a different weakness of the original hypothesis. These are documented research phases, not features of a current clinical or real-time product.

04–05

Statistical relationships, electrode reduction, robustness

Mixed-effects models account for repeated ratings within people. Training-only electrode selection probes whether fewer sensors suffice; the promising AF8 single-electrode lead did not replicate across sessions.

Independent gamma/theta replication NOT REPLICATED

On ds008836's 830-report silent-block subset, the amended primary slope was −0.072, one-sided p = 0.064. A previously reported successful mixed-model fit was invalid and the verdict was withdrawn.

07

Whole-scalp depth decoding MODEST SIGNAL

Riemannian covariance + ridge achieved a reported AUC of 0.609 over 39 people and 1,707 reports, better than the context-only baseline (0.519). This is relative, within-person depth ranking—not exact depth prediction.

Depth model results ↗
08

Try improving the depth model

Nine variants failed to confirm an improvement over plain covariance. A grouped-regularization rerun gave AUC 0.607; a separate 13-person holdout reached 0.551 (p = 0.057). The result is not equally strong in every sample.

09

Lead-up horizon & introspective fidelity

EEG from 60–120 s before a report had AUC 0.584 (Holm p = 0.020), but those bins contain more data than short near-report bins. Session-to-session fidelity stability was not supported (ρ = 0.15, p = 0.19).

08 — WHAT IT IS / IS NOT

A research platform, not a finished brain reader.

✓

What works today

Reproducible Python analysis components, documented comparisons, held-out-person evaluation, published results, and a website that explains those results.

×

What isn't demonstrated

A validated live concentration meter, clinical accuracy, robust single-electrode prediction, real-time EEG acquisition, or forecasting using only past data.
